# 电商视觉设计原则

本文件是判断依据，不是模板库。主图/副图的自适应结构见 [main-image-set.md](main-image-set.md)，详情页见 [detail-page-design.md](detail-page-design.md)。

## 一、从观看任务出发

- **搜索缩略图**：先识别商品与 SKU，再识别一个购买理由；真实列表尺寸下测试，不以“产品必须居中 70%”代替结果检查。
- **商品图库**：每张回答不同疑问；首图重身份，后续图补证据、尺度、细节、场景和实收。
- **详情页**：移动端连续阅读；一屏一个问题，文字与产品区在脚本阶段分配。
- **广告素材**：规则可能比商品图更严；促销、比较、数据和 CTA 需按广告规则另核验。

## 二、第一落点与动线

先用一句话写“0.5 秒看见什么”。常用动线是中心聚焦、Z 型、对角、视线/动作指引、尺度包围，但必须服务信息：

- 产品身份图：落点是包装/轮廓；
- 材质图：落点是可观察细节，产品仍可识别；
- 场景图：动作或视线导向产品使用关系；
- 信息图：标题 → 关键数据/属性 → 来源或限制；
- 收口图：实收内容/规格 → 服务或下一步。

装饰线、手势、人物视线、液体轨迹和光带指错地方，就会破坏动线。

## 三、层级与留白

- 一图一个核心信息；主标题、副标题、必要标签通常三级以内；
- 用尺度、字重、明度、位置和留白共同建立层级，不靠所有元素都加粗/发光；
- 文字行宽适合移动端，避免在繁忙照片上压小字；必要时用实色卡片或干净安全区；
- 留白必须说明用途：标题区、视线缓冲、产品轮廓、拼接过渡或动态字段。
- 图文可以用留白承字、产品轻咬合、物理指向、共享背景、证据叠合或场景连帧形成整体感；但参数、营养、FAQ 等信息屏允许清晰边界，不能为了“融合”牺牲阅读与校对。

## 四、色彩不是品类公式

色盘从四类输入推导：

1. 产品/包装真实颜色；
2. 品牌识别与目标气质；
3. 同平台货架环境与差异机会；
4. 场景语义与文字对比度。

常用 60/30/10 只是起点，不是硬标准。主色负责识别，辅色负责空间，点缀色只承担一个任务（关键标签、路径节点或动态信息）。食品不必都红橙、美妆不必都粉金、3C 不必都深蓝；这些只能作为待验证假设。

检查：产品与背景在灰度下是否分离；点缀色是否抢过产品；全套浅/深屏切换是否有节奏；文字对比是否足够。

## 五、摄影、尺度与真实感

- 产品透视自然；焦段、俯仰和镜头高度服务外形，不为戏剧性拉坏包装；
- 至少一张需要帮助理解尺寸时，提供可信参照物、手持或标注；
- 接触阴影最靠近物体处更实，远处更软；反射、折射、水花、蒸汽和凝露服从同一光源；
- 写明材质的粗糙度、边缘、高光形状、透光和纹理，不用“超真实 8K”替代；
- 人物场景写清动作、受力、握持、穿戴与产品尺度，避免空洞微笑摆拍。

## 六、统一与变化

套系统一来自版本化 Visual System：色盘角色、网格、字体、圆角/图标、产品身份、摄影后期、布光逻辑、场景族和固定母题。变化来自：

- 景别：全貌、局部、微距、环境；
- 主体位置：左/右/中心/越界裁切；
- 信息密度：大视觉、短信息、表格/路径；
- 版式原型：静物、场景、矩阵、编辑板、证据拼贴；
- 明暗节奏：浅底与深底有目的切换。

每张记录 layoutFingerprint：产品位置、产品尺度、镜头、信息密度、信息拓扑、背景类型。连续两张不重复“产品居中 + 顶部大字”，通常至少变化两项；连续规格/步骤/同条件比较可为了稳定对照而例外。变化不能破坏产品颜色、包装、标签方向和品牌系统，也不能为了追求不同而随意换组件语言。

## 七、证据与比较的视觉伦理

- 干净布光、清楚标签、真实材质和透明信息能营造可信感；这不是法律证据；
- 工厂、果园、实验室、专家、证书、报告、专利和评价只使用真实授权 `E` 资产；
- 比较图需要同对象、同条件、同单位、来源、范围和有效期；无证据改为本品属性板、同系列选择或适合/不适合；
- “使用前后”画面容易造成效果承诺，只有允许且有证据时使用；普通食品/敏感品类默认关闭。

## 八、促销与动态信息

- 价格、折扣、赠品、库存、物流、服务和活动期限属于动态字段；当前值及适用范围确认后可由豆包直接生成在图中，变更时局部改字或重生对应图；
- 不生成仿平台按钮、虚假倒计时或没有适用条件的“到手价”；
- 促销视觉仍要识别产品与 SKU，氛围不能掩盖在售内容物；
- 关键限制与费用条件邻接主张，不做“大字吸睛、小字免责”。

## 九、五秒质量检查

1. 缩到真实展示尺寸，产品和第一信息是否仍清楚？
2. 遮住所有文案，画面是否仍表达正确商品/场景，而非通用模板？
3. 每个道具、光效和图形能否解释自己的任务？
4. 灰度下产品、标题和背景层级是否分开？
5. 光、阴影、尺度、遮挡和材质是否属于同一物理空间？
6. 移走第三方参考图后，提示词是否自足且没有复制专属资产？
7. 所有文字、证据与动态字段是否可追溯、可更新、可校对？
