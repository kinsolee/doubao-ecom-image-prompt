# 拆解框架与拆解卡模板

## 使用原则

- 先定转化角色（图位 + 购买疑问），再拆画面：电商图是卖货工具，画风分析服务于转化分析。
- 每一维都要写出**可以直接放进提示词的具体描述**，不写笼统评价。
- 区分「观察到的事实」和「推断」：看得见的写事实，看不清的（品牌、真实材质、成分）标注"推断"。
- 拆解服务于两件事：让用户看懂这张图，让提示词有料可用。

## 第〇步：图位与购买疑问

### 图位判断

| 图位 | 页面任务 | 典型特征 |
|---|---|---|
| 主图 | 在搜索列表里赢得点击 | 产品大占比、强对比、信息极简 |
| 卖点图 | 让一个卖点被记住 | 单一卖点 + 强化元素/短文案 |
| 场景图 | 让用户代入使用时刻 | 生活环境、人物或使用状态 |
| 机制原理图 | 解释"为什么有效" | 剖面、箭头、步骤、成分放大 |
| 证据信任图 | 消除"可信吗"的疑虑 | 证书、报告、销量、评价元素 |
| SKU 组合图 | 帮用户选款/看清规格 | 多款并列、规格标注 |
| 详情页切片 | 承接长图叙事的一环 | 非常规画幅、上下文依赖 |

### 购买疑问

判断这张图主要回答用户哪 1–2 个问题（只选最主要的）：

这是什么？／适合我吗？／为什么有效？／可信吗？／怎么用？／选哪款？／凭什么点进来？

图位和购买疑问决定后面提示词的"画面任务"——同一个产品，回答"这是什么"和回答"为什么有效"是两张完全不同的图。

主图/副图还要判断它在目标平台商品图库中的**功能角色**：身份与点击、相关性与证据、选择依据、使用/规格、信任/实收，或类目强制槽位。用户未指定张数时不能自行固定五图；明确要 5 张且未另定顺序时，以 `FIVE_CONVERSION_ARC_V1` 为默认叙事，再按平台×类目规则与证据调整角色；详见 [main-image-set.md](main-image-set.md)。

### 整条详情页/模板拼贴的特殊处理

整条长页不是一张可直接迁移的 L/S 参考，而是一个 `SRC + ANALYSIS_ONLY` 源容器：

1. 先读完整页面，建立 `纵向边界 → 屏功能 → 购买疑问 → 主版式 → 产品占位 → 文字密度 → 上下过渡 → 可迁移机制 → 泄漏风险` 的 screen map；
2. 按语义屏边界拆解，不按固定高度平均切；裁片保留完整单屏、四边安全区和必要过渡带，不切产品、标题、阴影或卡片；
3. 原生分辨率保留，不把上采样当作版式质量；逐张确认屏型和边界；
4. 自有/授权完整单屏裁片可建议为 L/T；第三方未知权利原图仍只作分析，转成文字版式规则或去产品/文案/品牌/配色的抽象骨架；
5. 整条母本永不进入模型 references。避免把长图比例、拼贴网格、竞品产品、示例文字和重复卡片带入成品。

完整参考协议见 [visual-reference-and-style-system.md](visual-reference-and-style-system.md)。

### 参考品质基线与创意变体

反推不是把参考图概括成“同款高级感”，而是先找出 3–5 个真正撑起完成度的**承重机制**：主体尺度与落点、版式骨架与留白节奏、光影层次、材质细节、色彩关系、文字与画面融合方式。它们形成 `referenceQualityFloor`；迁移成用户产品后不得被简化成普通产品居中、换色或换背景。

用户未指定变体数时，文本方案默认给 4 个有明确差异的方向：

1. **忠实迁移基准**：最大程度保留承重机制，只替换产品、文案、事实与品牌；
2. **构图升级**：改变主体位置、裁切或镜头，但保留光色与材质完成度；
3. **场景叙事**：把同一卖点放入更具体的使用动作与空间；
4. **信息设计**：强化文字、数据或证据与产品的融合关系。

四个方向不能只是颜色、背景或道具小改。每个方向写清“保留哪些承重机制 / 只改变什么 / 为什么仍适合该商品”。实际生图先用这四个低/中成本锚定草案比较；用户明确只要一张或构图已锁死时可缩减。若生成结果在主体层级、光影、材质、版式或文字融合中有两项明显弱于参考基线，先修 prompt、参考角色或锚点，不把它包装成“更原创”。

## 十维观察清单

### 1. 产品主体

- 是什么产品？单品还是组合？有无包装同框？
- 产品在画面中的位置（居中/偏左/偏右/前景）和占比（约百分之几十）？
- 产品朝向和姿态：正面、侧 15–30°、悬浮、倾斜、开盖/展开状态？

### 2. 画面构图

- 构图类型：居中对称 / 三分法 / 对角线 / 俯拍平铺（flat lay）/ 框架式 / 留白式？
- 视觉动线：第一眼落点 → 第二眼 → 最后停在哪？
- 前景、中景、背景各放了什么？有没有引导视线的线条或元素？

### 3. 核心卖点

- 这张图想让人记住的一个卖点是什么？
- 它是靠什么表达的：道具隐喻（冰块=清凉）、对比演示、局部特写、场景暗示、文字直说？
- 有没有次要卖点？它们的视觉权重是否明显低于主卖点？

### 4. 标题文案

- 有无文字？主标题说什么、副标题说什么？
- 字号层级：几级文字？最大的字占画面多宽？
- 文字位置和产品的关系：压在留白处还是压在产品上？横排竖排？
- 文字风格：衬线/无衬线/书法体/描边加粗？

### 5. 视觉风格

- 一句话定风格：极简高级 / 清新自然 / 国潮 / 科技感 / 促销爆炸 / 杂志编辑风 / ins 风？
- 靠什么营造：配色克制、留白多、道具少 → 高级；饱和撞色、元素密 → 促销。

### 6. 颜色搭配

- 主色（占比最大）、辅色、点缀色分别是什么？给出具体色感（"奶油白"而不是"白色"）。仅凭视觉判断的 HEX 只能标“近似设计值”，正式品牌规范才是精确色值。
- 对比方式：互补撞色 / 同类渐变 / 低饱和莫兰迪 / 黑白+一点亮色？
- 产品色和背景色的关系：融合（氛围感）还是对比（跳出感）？

### 7. 使用场景

- 场景在哪：纯色棚拍 / 桌面一角 / 厨房 / 浴室 / 户外 / 抽象舞台？
- 场景传达什么时刻和生活方式（清晨护肤、露营野餐、深夜书桌）？
- 场景道具有哪些？每个道具在替产品说什么话？

### 8. 光影氛围

- 主光方向：顺光 / 侧光 / 侧逆光 / 顶光 / 底光？
- 光的软硬：柔光箱般均匀，还是硬光带明确投影？
- 色温：暖黄 / 中性 / 冷白？有没有彩色氛围光？
- 阴影和高光：产品边缘有无高光勾边？投影是贴地短影、长拉影还是无影？有无倒影？

### 9. 材质细节

- 产品材质怎么被表现：磨砂颗粒、玻璃透光、金属拉丝反光、织物纹理、水珠、奶油质地拉丝？
- 环境材质：大理石台面、原木、绒布、水面、亚克力板？
- 有没有强化质感的特写元素（飞溅、涂抹痕迹、切面）？

### 10. 镜头角度

- 视角高度：平视 / 45° 俯拍 / 90° 顶拍 / 低角度仰拍？
- 距离与景别：特写 / 近景 / 中景？
- 景深：背景全虚化 / 微虚 / 全清晰？焦点锁在哪个细节？
- 等效摄影语言：微距、50mm 平拍、广角带环境？

## 点击逻辑分析（四问）

拆完十维后回答，每问 1–2 句，落到具体元素：

1. **第一眼落点**：0.5 秒内先看到什么？是因为它最大、最亮、对比最强，还是在视觉中心？
2. **卖点强化机制**：哪些元素在替卖点说话？写成"元素 → 传达含义"的映射。
3. **信息层级**：产品、文案、道具、背景的主次顺序；留白留在哪，为什么留在那。
4. **差异化**：与该品类常见图相比，这张图敢在哪里不一样（角度、配色、场景、情绪）？

## 迁移清单

拆解卡中固定列出两栏，划清"学手法"和"抄内容"的边界（这是把参考图手法迁移到用户产品的依据）：

- **可迁移（手法层）**：构图方式、信息摆放顺序、图位任务、卖点表达结构（元素→含义的隐喻方式）、证据摆放位置、产品占比与视觉节奏、光影配色手法、镜头角度。是否可以像素参考还要看 owner/authorization；第三方 analysis-only 只迁移抽象方法。
- **不可照搬（内容层）**：对方品牌名与 logo、包装设计、文案原文、证书与检测报告、价格与促销信息、功效数字、"第一/最强/国家级"类表述、代言人形象。

不可照搬项的处理：品牌换成用户品牌；文案按用户真实卖点重写并直接生成；证据类元素只保留版式位置，内容必须替换为用户真实授权素材，缺少证据就删除该元素，不留伪证据占位。
