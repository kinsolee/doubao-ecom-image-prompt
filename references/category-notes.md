# 品类视觉要点与主张边界

本文件用于风险筛查，不替代当前法律意见或平台审核。每次上架按目标地区、平台、类目和日期核验官方规则。总原则：**画面会形成事实暗示；不能用漂亮场景、图标或小字替用户虚构成分、性能、产地、资质和效果。**

## 一、所有营销性图内主张先过六关

商品名称、规格、价格、售卖单位等依法/依平台必须展示的信息，首先按电子商务与 `R-LISTING` 规则保证完整、真实、准确、及时；带说服目的的卖点、比较、引证、促销与投放内容再按广告法、互联网广告管理和 `R-AD` 从严。普通商品必填字段与广告素材不能混成同一规则类型。

1. **产品匹配**：主张是否精确属于本 SKU/变体/地区版，而非同品牌其他型号或竞品；
2. **允许表达**：目标品类与渠道是否允许该主张；医疗、保健、广告投放等边界另核验；
3. **证据强度**：文字强度不超过 `F/E`。数字、比较、专利、认证、功效必须能回到底层证据；
4. **条件邻接**：适用对象、范围、单位、期限和限制与主张同屏清晰展示；
5. **跨入口一致**：标题、主图、详情、SKU、直播/广告与实物口径一致；
6. **可读与可校对**：高风险/精确文字也逐字写入豆包 prompt 直接生成，上架前 OCR 与人工逐字通过。

“助力、有助于、可能、因人而异”不能挽救无依据或本身禁止的宣称。免责声明也不能修复客观虚假或误导；限制条件不能藏成低对比小字或全部放到末屏。

### 绝对化与百分比

“国家级、最高级、最佳”等广告法明确列举的绝对化用语默认禁用；“第一、唯一、顶级、全网最低”等高风险词只有在当前法律/平台语境与完整证据审查通过时才考虑，skill 默认不生成。

不要把所有 `100%` 机械当成同一种禁词：`100%果汁`、`100%棉`可能是在描述可核验的成分/材质比例，也可能在具体语境中造成误导。只有包装、标准、检测或官方同 SKU 资料支持，且平台允许时才使用；`100%有效/治愈/满意`等效果保证默认禁止。数字必须写清口径和来源。

### 比较、前后对比与数据

- 对象、测试条件、单位、来源、适用范围、有效期与底层报告齐全才做；
- 不点名贬损第三方，不用灰败/损坏竞品制造虚假差异；
- “使用前后”属于高风险效果表达，默认关闭；无充分证据改为产品特征、使用步骤或适合/不适合；
- 小红书/广告投放等渠道可能对比较和数据有更严要求，按 `Rxx` 执行。

## 二、食品与饮品

**视觉重点**：真实原料/配料、风味口感、液体状态、饮用时刻、包装规格、背标、储运。倾倒、气泡、冰块、切面、水珠必须服从产品真实颜色、透明度、黏度和成分。

**边界**：

- 普通食品不宣称疾病预防治疗或保健功能，不用症状痛点、人体器官、前后效果、特定疾病人群暗示功效；
- 原料同框会形成成分暗示；没有该成分就不摆，类目通识中的原料利益不能转嫁成本品效果；
- HPP/NFC/冷榨/有机/零添加/产地/营养数字/“一瓶约等于 N 个水果”等需本 SKU 事实与证据；
- 配料、营养、标准号、储运和保质期根据真实背标逐字写入豆包 prompt 直接生成，并逐项校对；
- 保健食品只使用批准/注册/备案允许的内容与法定警示语，具体措辞由当前批件、平台和法务确认。

## 三、护肤与美妆

**视觉重点**：膏体/精华黏度、滴落与拉丝、粉体颗粒、玻璃透光、磨砂与高光、使用质地和包装细节。

**边界**：成分浓度、功效、临床数据、医美背书、适用人群和“无添加”需备案/检测与同 SKU 证据；成分教育不得偷换为产品效果。分子、细胞、皮肤层示意只有真实机制和合规依据时使用，并明确示意，不能用发光粒子冒充科学。

## 四、服装与配饰

**视觉重点**：版型、面料纹理、垂坠/挺括、车缝、五金、上身动作、尺码与清洗护理。

**边界**：真丝、羊绒、羽绒、皮革、功能面料等材质比例与等级必须匹配标签/检测；“画得像”不等于成分。模特不仿可识别明星/真人；不同颜色/尺码 SKU、标题、主图和详情保持一致。尺码表由豆包在成图中完整直出并逐项校对。

## 五、家居与家电

**视觉重点**：产品与空间尺度、真实使用状态、安装/收纳、结构细节、台面/木/金属/织物的材质关系。

**边界**：容量、功率、噪音、能耗、承重、除菌率和兼容性需证据；不能画不存在的内部结构、雾量、火焰或净化效果。强制认证/能效等真实标识按平台指定槽位放原件，不由 AI 生成。

## 六、数码与 3C

**视觉重点**：接口、按键、镜头模组、金属/玻璃/磨砂、尺寸、兼容关系、配件和使用状态。深色与边缘光只是风格选择，不是“科技感”唯一公式。

**边界**：芯片、功率、续航、速度、防护等级、协议与认证必须对应型号；屏幕/UI 不伪造系统功能，已确认的界面文字和参数逐字写入豆包 prompt，生成后 OCR/目视校对，错字局部改。不得出现他牌商标、虚假认证或不存在的接口。

## 七、运动器材、健康与医疗相关

先精确判断普通运动用品、医疗器械、保健/健康产品的监管身份，不能把它们混成“从严到宽”的单一层级。

- 普通运动用品不医疗化，不写治疗、修复、矫正、康复等，效果与承重数据需证据；
- 医疗器械只在注册/备案与说明书允许范围内表达，适用范围、禁忌和警示邻接；
- 不用人体病灶、诊断示意、白大褂、专家或临床场景制造资质错觉。

## 八、资质、品牌与 AI 画面

- 工厂、果园、实验室、团队、专家、证书、报告、专利号、评价和销量只使用真实授权 `E` 资产；
- AI 可做中性示意背景，但必须避免被理解为用户真实能力/基地；必要时显著标“创意示意”；
- 保留提示词、参考图角色、生成/编辑记录和 AI 元数据；按现行规则区分生成服务提供者添加标识、传播平台核验/展示、发布用户主动声明，以及任何主体不得恶意删除/隐匿标识。商家使用平台声明功能并遵守目标渠道要求，不默认自行同时制作所有显式水印与隐式元数据；
- 第三方 logo、包装、字体商标、代言人和专属画面不迁移。
